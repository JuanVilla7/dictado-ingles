---
description: Instala dependencias y levanta el servidor de desarrollo
---
1. En `frontend/`, corré `npm install`.
2. Corré `npm run validate` para confirmar que todo está bien (lint + tests + build).
3. Levantá `npm run dev` en segundo plano y decime la URL (http://localhost:5173/dictado-ingles/).
4. Si algo falla, mostrame el error y proponé cómo arreglarlo antes de tocar nada.
